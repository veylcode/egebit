# Egebit Web

- Публичный репозиторий содержит только статический интерфейс. Никаких .env, ключей, базы, пользовательских условий, личных ссылок входа или отчётов с данными участников.
- Рабочий API и бизнес-логика находятся в соседнем Egebit/egebit/web.py и используют существующие очередь, квоты, шаблоны и sandbox. Не создавайте независимую очередь или обход бюджета.
- Вход через персональный /web в группе. Никакого доверия к переданному клиентом Telegram ID или признаку администратора.
- С 19.10.2026 решение доступно без входа: автоматически создать /api/guest, хранить отдельный токен в localStorage. Чужие заявки и админка закрыты сервером. После /web — история Telegram и публикация в группе; гостевые условия и ответы остаются в браузере. Не смешивать эти пояснения.
- Без лишних декоративных слоганов. Номера шагов/карточек — 1, 2, без ведущих нулей. Исходные ID задач и даты не менять.
- Отображайте реальный статус. Код из результатов рендерится как текст, а не HTML. Не выполняйте Python/HTML из файлов пользователя.
- Публикация GitHub Pages: veylcode/egebit, main, корень. Сохраняйте текущий origin/API и мобильную раскладку.

- С 2.5.0 есть отдельные регистрация и вход по логину/паролю. Telegram /web не менять. 15 задач/5 часов на ключ браузера; без IP-квоты и отдельного гостевого бюджета. Никаких клиентских назначений admin. Гостевой device principal отличается от аккаунта, после выхода история аккаунта закрыта. Хранить токены Telegram, аккаунта и устройства отдельно. APInex отключён.
