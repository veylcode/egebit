# Egebit — личный кабинет

Статический интерфейс для GitHub Pages. Рабочая очередь, проверка доступа и обработка файлов находятся в Egebit на VDS. Ключи Telegram и провайдеров не входят в этот репозиторий.

Для решения вход не нужен. Лимит — 15 задач за 5 часов на сохранённый ключ браузера устройства, без общей квоты сети и отдельного гостевого API-бюджета. Ключ сохраняется при обновлении сеанса, регистрации и выходе; очистка данных сайта его сбрасывает. Сетевые ограничения частоты запросов, обработка и общий денежный бюджет сервиса сохраняются. Гостевые условия и ответы не отправляются в Telegram.

Кнопки «Регистрация» и «Войти» используют отдельный аккаунт сайта: логин/пароль, история с разных устройств, гостевые заявки переходят при регистрации. Публичная регистрация не назначает администратора. Пароли/данные/сеансы хранятся только на приватном backend; в публичном Git их быть не должно.

Необязательный вход: `/web` в разрешённой группе → персональная одноразовая ссылка, 5 минут. Сеанс Telegram хранится только в sessionStorage вкладки и действует до 8 часов. API проверяет членство в группе при каждом запросе; административные действия доступны числовому владельцу бота. В этом режиме подключаются история и квота Telegram, а условия и результаты публикуются в группе.

Кабинет поддерживает задачи 1–27, текст и до 5 файлов (4 МиБ каждый, 16 МиБ суммарно), несколько условий во вложении, очередь, последние 100 заявок, отдельные результаты, копирование/скачивание Python, уточнения, TXT/CSV с данными, отмену и повтор.

В 2.6.0 перед решением показывается редактируемый предпросмотр: текст, номер ЕГЭ и ID источника, удаление лишних и добавление пропущенных условий. Решение начинается только после подтверждения. Вложения можно объединить как страницы одной задачи. Выбирается «Код и ответ» или «С объяснением». Готовые решения сохраняются в личные именованные подборки с поиском и фильтром; кнопка «Ответ неверный» передаёт снимок условия/результата владельцу. Расходы и техническая диагностика доступны только владельцу. Предпросмотр расходует API при распознавании изображений.

Владелец управляет Python/TXT-шаблонами, инструкцией, моделями, паузой, лимитами, кэшем, эмодзи и сверкой тарифа; видит общую очередь, расходы, точные шаблоны и жалобы на ответы со статусами проверки. Изменения сохраняются в основной БД бота. Кнопки и права проверяются сервером.

Запуск для просмотра: `python -m http.server 5174 --bind 127.0.0.1`. Производственный API разрешает только origin GitHub Pages, поэтому вход/данные в локальном просмотре намеренно недоступны. Нужна публикация в `https://veylcode.github.io/egebit/`.

Настройка API описана в WEB.md закрытого проекта Egebit. `API` в app.js и `connect-src` в index.html должны указывать на один HTTPS backend. Сертификат обслуживается Caddy. Сборка и внешние JavaScript-библиотеки не нужны.

В 2.7.0 кнопка «Скачать подборку ZIP» выгружает выбранную тему либо все свои подборки: до 500 решений и 10 МиБ исходного текста. Внутри для каждой задачи отдельные condition.txt, solution.py, answer.txt, explanation.txt и verification.txt. Архив доступен только текущему пользователю; сервер его не сохраняет, код при экспорте не запускает.

Egebit подготовлен для установки как PWA: manifest.webmanifest, PNG-иконки 192/512, Apple Touch и maskable, кнопка установки внизу страницы. На iPhone — Safari → «Поделиться» → «На экран Домой». Установка не меняет вход, историю или лимиты. Новые решения и подборки требуют интернета. Service worker кэширует только статическую оболочку этого проекта; API, токены, условия, результаты и ZIP в Cache Storage не записываются. Обновление не перезагружает незавершённую форму без действия пользователя.

Добавлены узкие встроенные варианты №7 (несжатый звук), №8 (слова с/без повторений и точным количеством буквы), №14 (цифра в основании 2–36), №23 (прибавление/умножение, обязательная/запрещённая точка). Они используют прежние очередь, квоту и песочницу без платного API; неподдерживаемые формулировки передаются прежнему решателю. Распознавание фотографий по-прежнему требует API. Для PWA использована [документация MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

В 2.8.1 на главной — короткий статус ИИ и время проверки. Мониторинг работает на сервере, даже когда сайт закрыт. Публичный статус не содержит денег, тарифов и технических причин отказа; данные владельца защищены серверной проверкой прав. Потеря связи не оставляет зелёный индикатор. Контроль соединения не запускает платную генерацию и не повторяет заявки.
