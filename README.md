# Egebit — личный кабинет

Статический интерфейс для GitHub Pages. Рабочая очередь, проверка доступа и обработка файлов находятся в Egebit на VDS. Ключи Telegram и провайдеров не входят в этот репозиторий.

Для решения вход не нужен. Лимит — 15 задач за 5 часов на сохранённый ключ браузера устройства, без общей квоты сети и отдельного гостевого API-бюджета. Ключ сохраняется при обновлении сеанса, регистрации и выходе; очистка данных сайта его сбрасывает. Сетевые ограничения частоты запросов, обработка и общий денежный бюджет сервиса сохраняются. Гостевые условия и ответы не отправляются в Telegram.

Кнопки «Регистрация» и «Войти» используют отдельный аккаунт сайта: логин/пароль, история с разных устройств, гостевые заявки переходят при регистрации. Публичная регистрация не назначает администратора. Пароли/данные/сеансы хранятся только на приватном backend; в публичном Git их быть не должно.

Необязательный вход: `/web` в разрешённой группе → персональная одноразовая ссылка, 5 минут. Сеанс Telegram хранится только в sessionStorage вкладки и действует до 8 часов. API проверяет членство в группе при каждом запросе; административные действия доступны числовому владельцу бота. В этом режиме подключаются история и квота Telegram, а условия и результаты публикуются в группе.

Кабинет поддерживает задачи 1–27, текст и файлы до 4 МБ, несколько условий во вложении, очередь, последние 100 заявок, отдельные результаты, копирование/скачивание Python, уточнения, TXT/CSV с данными, отмену и повтор.

Владелец управляет Python/TXT-шаблонами, инструкцией, моделями, паузой, лимитами, кэшем, эмодзи и сверкой тарифа; видит общую очередь, расходы и точные шаблоны. Изменения сохраняются в основной БД бота. Кнопки и права проверяются сервером.

Запуск для просмотра: `python -m http.server 5174 --bind 127.0.0.1`. Производственный API разрешает только origin GitHub Pages, поэтому вход/данные в локальном просмотре намеренно недоступны. Нужна публикация в `https://veylcode.github.io/egebit/`.

Настройка API описана в WEB.md закрытого проекта Egebit. `API` в app.js и `connect-src` в index.html должны указывать на один HTTPS backend. Сертификат обслуживается Caddy. Сборка и внешние JavaScript-библиотеки не нужны.
